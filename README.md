
# Sales Database Analyzer

A Python project that uses SQLite and SQL queries to analyse sales data.

## Features

- Creates a sales database.
- Inserts sample sales records.
- Calculates total revenue.
- Groups revenue by city and product.
- Filters orders above €500.
- Finds the highest-value order.

## Technologies

- Python
- SQLite
- SQL

## How to Run

Run the following command:

`python sales_database.py`

The database file is created automatically.
